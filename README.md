### Projects

#### 🛒 WhatsApp Conversational Grocery Ordering System

`Python` `FastAPI` `LLM/NLP` `OAuth 2.1`

A production-style conversational ordering backend that turns multilingual WhatsApp voice and text messages into structured grocery orders.

Built around **WhatsApp Cloud API, Groq Whisper and Gemini**, with OAuth 2.1 PKCE, spending limits, double confirmation, real-time price validation and timezone-aware scheduling.

[Repository](https://github.com/pratyush-vatsa)

---

#### 🔐 Secure Image Steganography Web Application

`Python` `Flask` `AES-256` `Pillow` `NumPy`

A web application combining **AES-256 encryption with adaptive LSB steganography** to securely hide encrypted data inside images.

Supports batch processing of 50+ images per session and achieved **PSNR > 45 dB and SSIM > 0.99** across tested image formats.

[Repository](https://github.com/pratyush-vatsa/Stegnography-Project) · [Live Demo](https://securesteganography.com/)

---

#### 🕵️ AI-Driven Pentesting Automation Platform

`React` `Node.js` `MongoDB` `n8n` `Docker`

An automated security testing platform that orchestrates **Nmap and OpenVAS** scans through n8n workflows and Dockerized environments.

Uses Gemini to turn scan results into **CVSS-rated vulnerability reports, prioritized findings and remediation guidance**.

Reduced manual reconnaissance by ~60% and vulnerability triage time by ~70%.

[Repository](https://github.com/pratyush-vatsa/AI-Driven-Detection-Engineering-Lab-Platform-using-n8n-Automation)
